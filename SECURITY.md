# Security

Report a vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/TusanHomichi/PSIV/security/advisories/new)
for this repository, not in a public issue or discussion. Include what is
affected, how to reproduce it, and the commit you tested.

PSIV runs locally from a source checkout and reads only files you give it (your
ROM, the data pack built from it, and your saves). Reports about that code,
its build scripts and the repository's automation are in scope; the original
game and third-party components are not, and go to their own projects.
